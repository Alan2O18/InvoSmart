# v0.0.8

日期：2026-03-09

## 主題

後端基礎建設與測試覆蓋率全方位提升 (總覆蓋率 77% → 84%)。

## 更新重點

**Phase 1 (77% → 82%)：核心背景任務與基礎設施防護**
1. 建立 `database/core.py` 的 Session 生命週期與 SQLite 初始化防呆測試。
2. 針對 `utils/config.py` 補齊邊界與 Fallback 組態載入的回退防線測試。
3. 為 `pdf_worker.py` 與 `workers.py` 打造完整防護網，覆蓋 Queue 取值異常、Exception 捕捉與 Shutdown 優雅退出的測試。
4. 針對 `excel_exporter.py` 的報表產出、Empty Job 防呆與狀態更新進行深度測試。
5. 修復 `routers/pdf.py` 漏洞，拒絕非 PDF 檔案上傳時正確回傳 HTTP 400，並強化下載與轉換情境的測試。
6. 全面刪除 8 個無效/廢棄的暫存測試檔，並清理殘留的 `.pytest_cache` 快照與 Coverage 垃圾資料。

**Phase 2 (82% → 84%)：進階錯誤處理、幾何驗證與 LLM 邊界實測**
1. `contour_validator.py` 單元測試覆蓋率達 100%，補齊座標幾何變形 (包含菱形邊界) 與長寬比保護機制的防禦確認。
2. 擴充 `llm_handler.py` 測試覆蓋深度，模擬系統錯誤 (如 Ollama 離線導致 SystemError)、空內容回應及 JSON 解析破裂的復原流程。
3. 增加 `routers/projects.py` 與 `routers/processing.py` 控制器各類中斷與失敗操作 (CRUD) 的 Exception 情境模擬。
4. 修正並對齊早期測試中的邊界 Mock 回應。

**Phase 3 (收尾階段)：Artifact 清理與影像/匯出演算法邊界實測**
1. 深入測試 `image_preprocessor.py` (56% → 100%)：包含邊緣偵測的維度驗證、空圖片的防呆與降噪輪廓排序準確度測試。
2. 深入測試 `export.py` (71% → 100%)：完成報表打包邏輯 (Archive logic)、Word/Excel 的依賴委派執行 (Delegation) 測試。
3. 清除覆蓋率掃描所殘留的隱藏檔案（如 `.coverage`）。

## 影響

- 系統防禦力大幅躍升，最危險的核心底層（資料庫生命週期、背景任務佇列、檔案匯出）擁有完整的防護網與例外分支捕捉能力。
- 單元測試與整合測試總量攀升至 425 個且全數綠燈 (Exit code 0)，執行效能優化至約 22 秒內完賽。
- 包含 `engine/` 與 `processing/` 的核心邏輯與邊界情境極大程度通過防禦實測，安全性大幅脫離先前的缺口狀態。
