# 版本紀錄 - v0.0.16 (架構重構與技術債清理)

日期：2026-04-12

---

## 🎯 重點更新 (Key Focus)
本版本聚焦於「不新增大型功能」的重構與防呆：
- 非阻塞 async 路徑修復（避免 Event Loop 被同步 I/O 卡死）
- 印章模組三層化（Router / Service / Repository）
- `FileOps` 刪檔流程改為延遲 GC（降低共用檔誤刪風險）
- 針對 voucher/groups/dependencies 的既有 bug 修復

## ✨ 主要更動 (Implemented)

### 1) 架構與守門
- 新增 AI guard skill：`.agent/skills/nknu-vlm-guard/SKILL.md`
- 新增架構守門腳本：`scripts/check_architecture_guards.py`
- 新增 `CacheMixin`：`backend/engine/cache_mixin.py`，抽離 preview cache 與 semaphore 共用邏輯
- 新增 `StampRepository`：`backend/repositories/stamp_repository.py`
- 新增 `StampService`：`backend/engine/stamp_service.py`
- `StampProcessor` 新增純處理方法：`extract_stamps()`（不碰檔案 I/O、不碰 DB）

### 2) FileOps 非阻塞與刪檔安全
- `backend/engine/file_ops.py`
  - 透過 `CacheMixin` 共用 `_optional_semaphore()`，統一 semaphore 模式
  - `_prepare_tasks` 改為 `asyncio.to_thread()` 執行 `cv_imread_chinese` / `receipt_splitter.split` / 影像寫入
  - `add_project_files` 的 `mkdir/copy` 等同步 I/O 改為 `asyncio.to_thread()`
  - `add_pdf_files` 的 `mkdir/copy/PDF 首頁渲染` 改為 `asyncio.to_thread()`，並抽出 `_render_pdf_first_page_to_bgr()`
  - `delete_job_files` 改為延遲 GC 佇列 + `flush_deferred_gc()`；避免立即刪除共用 `image_path`
  - 檔案行數由 958 降至 672，通過單檔行數守門
- `backend/engine/core.py`
  - `delete_job()` 在 DB 刪除後觸發 `flush_deferred_gc()`

### 3) Voucher / Groups / Dependencies 修復
- `backend/routers/voucher.py`
  - `get_voucher_image`：Job 不存在回傳 `404 NOT_FOUND`（由 403 修正）
  - `_load_image_bytes`、`generate_from_layout`、template preview、layout JSON 寫入改為 `to_thread`
- `backend/engine/voucher_generator.py`
  - `generate_voucher_pdf` 改用 context manager，避免異常時資源未釋放
- `backend/routers/groups.py`
  - `glob/stat/rmtree/write/unlink` 改為 `to_thread`
- `backend/dependencies.py`
  - `get_db()` 加入 `AsyncSessionLocal is None` 時回傳 503

### 4) 死碼與清理
- `backend/processing/perspective_transform.py` 刪除 no-op `fix_orientation()`
- `backend/processing/receipt_splitter.py` 與 `backend/engine/file_ops.py` 移除 `fix_orientation` 呼叫
- `backend/routers/suggestions.py` 移除重複與未使用 import
