# v0.0.4

日期：2026-03-07

## 主題

嘗試修補 Voucher Editor，卻引入嚴重回歸的問題版本。

## 更新重點

1. 嘗試修正憑證文字位置與刪除選取行為，但改動直接碰觸 `canvasLoading`、非同步載入保護與 Canvas 同步流程。
2. 後端以 `fitz.search_for()` 對齊欄位標題文字，而不是實際輸入格 baseline，導致憑證編號、金額、日期全部印錯位置。
3. 前端預覽與後端 PDF 各自使用不同座標來源，畫面看似可用，實際輸出仍然偏移。
4. 憑證編號、金額、日期等欄位排版規則未定型，且缺少共享設定來源與回歸測試保護。

## 影響

- 多頁資料可能互相污染，出現「整批頁面串在一起」的回歸
- 刪除選取可能失效，甚至誤傷整頁狀態
- PDF 產出結果不可信，成為 V0.0.5 / V0.0.6 重整的直接起點
