# v0.0.27 (預計發佈) - Excel 預算編輯器與樹狀摺疊總覽

## 新增功能
* **Excel 式預決算編輯器 (`BudgetEditorView.vue`)**：
  * 全螢幕 Excel-like 試算表。
  * 支援鍵盤箭頭鍵、Tab、Enter 等焦點切換導航。
  * 支援直接複製/貼上 Excel/Google Sheets 儲存格資料 (TSV 解析)。
  * 表尾金額動態自動計算與合計。
* **發票細項雙向回存系統**：
  * 決算表可直接編輯已處理發票的明細（Jobs），並在保存時自動分組打包回存至發票 JSON。
* **樹狀摺疊總覽大表 (`ProjectsOverviewView.vue`)**：
  * 可摺疊/展開的專案管理看板。
  * 即時顯示所有專案的預算總額、決算總額及差額。
