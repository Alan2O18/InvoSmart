# v0.0.23 嚴重缺陷修復與驗證收尾

**專案狀態**: ✅ 已完成

---

## 執行摘要

v0.0.23 是承接 v0.0.22 的高優先度修補版，針對虛擬人員初始化、PDF 預覽、印章旋轉與模板編輯器四個關鍵缺陷進行收尾修正。這一版的目標不是擴充新功能，而是把先前已建立的 PDF 任務線與管理中心補到可穩定使用的狀態。

---

## 主要修復項目

### 1. 虛擬人員初始化與啟動流程整理
- 修正 `backend/main.py` 的啟動引用與資料庫 session 取得方式，讓 `ensure_virtual_persons()` 能在啟動階段正常執行。
- 搭配 `scripts/upgrade_db_v0_0_20.py`，可將舊版 `stamps`、`groups` 等殘留 schema 重建為新版結構，避免虛擬角色缺失造成印章管理失效。

### 2. PDF 任務預覽改為內嵌顯示
- 在 `backend/routers/pdf_tasks.py` 的 PDF 檔案端點改用 inline 顯示方式，避免瀏覽器把 PDF 視為下載檔。
- 讓前端 `/pdf-tasks/:id/editor` 能以 iframe 或內嵌檢視的方式直接預覽工作檔。

### 3. 印章蓋印改成真實旋轉與透明背景保留
- 新增 `backend/utils/stamp_ops.py`，使用 Pillow 讀取印章圖，轉為 RGBA 後執行隨機角度旋轉。
- `backend/engine/voucher_generator.py` 與 `backend/routers/pdf_tasks.py` 共同改用旋轉後的 PNG bytes，讓 `insert_image()` 不再只是硬塞原圖。
- 使印章輸出具備 ±10° 的自然變化，並保留透明通道。

### 4. 視覺化模板編輯器完成落地
- 新增 `frontend/src/views/StampTemplateEditorView.vue`，提供 A4 比例畫布與角色座標編輯。
- `frontend/src/router/index.js` 新增 `/stamp-templates/create` 與 `/stamp-templates/:id/edit`。
- `frontend/src/views/StampsManagementView.vue` 取消 JSON textarea 的寫法，改為導向模板編輯器的操作流程。

---

## 版本結果

- 虛擬人員初始化與印章綁定流程恢復正常。
- PDF 任務文件可在系統內預覽，不再被強制下載。
- 印章蓋印具備真實旋轉效果與透明背景。
- 蓋章模板管理從手填 JSON 進一步升級為可視化編輯。
