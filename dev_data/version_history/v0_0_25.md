# v0.0.25 架構重構與邊界強制執行

**專案狀態**: ✅ 已完成

---

## 執行摘要

v0.0.25 重塑了後端三層架構邊界，完成了關鍵服務的解耦，並大幅精簡了前端的頁面架構。在後端，我們嚴格限制了 Router 對 `numpy`、`cv2` 及 `fitz` 的存取，將 PDF 與圖像裁切邏輯封裝至獨立 Service 中；在前端，將 5 個分散的舊視圖整合至 Modal 與統一視圖，大幅提升了程式碼的可維護性。

---

## 主要修改項目

### 1. 後端架構解耦與邊界限制 (3-Layer Boundary Enforcement)
- **PdfTaskService**: 封裝所有 PDF 頁面分割、渲染與印章嵌入操作，消除 Router 層中對 `fitz` (PyMuPDF) 的引用。
- **ResplitService**: 整合發票自動分割及手動二切邏輯，移除過時的 `file_ops.py`，保持 `core.py` 注入邏輯的簡潔。
- **ImageCodecAdapter**: 移至 `engine/`，定位其作為影像編解碼轉換服務的職責。
- **檔案式 Repository**:
  - `PdfTaskRepository` (資料夾: `backend/data/pdf_tasks/`)：管理 PDF 切割任務。
  - `StampTemplateRepository` (資料夾: `stamp_templates/`)：管理印章模板 JSON 設定。

### 2. 前端視圖精簡與 Modal 化整合 (Frontend Consolidation)
- **ProjectSettingsModal.vue**: 從原有的 `EditProjectView` 抽取，改為以 Modal 形式在專案細節頁面直接顯示。
- **VoucherEditorView.vue**: 整合原有的 `JobEditorView`，改為右側折疊式 Metadata 編輯 Sidebar，並支援以 `editJobId` 查詢參數自動開啟該發票。
- **StampsManagementView.vue**: 整合原有的上傳及座標設定頁，改以對話框精靈引導完成配置。
- **VoucherTemplateConfigView.vue**: 恢復並串接視覺化憑證範本座標設定畫布，支援拖曳文字錨點、安全區與蓋章死區。
- **路由清理**: 刪除了 5 個已整合的舊視圖路由，並清理轉址定義。

### 3. 資料庫正規化與 Migration
- 移除了 ORM 模型中的 `flattened_data` 及 `flattening_status` 屬性。
- 生成了 SQLite-safe 的 Alembic 遷移腳本（版本號 `397469f3f669_remove_flattened_data_columns.py`）並完成資料庫升級。

### 4. 工具與套件精簡
- 在 `requirements.txt` 中移除了 `pandas`、`xlsxwriter` 及 `requests` 等大型相依套件，報表匯出統一改用原生 `openpyxl` 實作。
- 前端移除了 `pdfjs-dist` 相依。
