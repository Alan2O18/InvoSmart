# v0.0.24 推薦詞管理與地點下拉選單

**專案狀態**: ✅ 已完成

---

## 執行摘要

v0.0.24 補齊了推薦詞系統在日常建檔流程中的缺口。除了在後端實現完整的推薦詞管理 (CRUD) API 外，亦在前端 `SettingsView` 提供了視覺化的推薦詞編輯介面；同時，將活動地點欄位升級為下拉推薦選單，使用戶在新增與編輯專案時，能快速選用既有的地點推薦詞，並在建立或更新活動時自動回收新地點。

---

## 主要修改項目

### 1. 後端推薦詞管理 (CRUD) 補齊
- 在 `backend/repositories/suggestion_repository.py` 補齊 `list`、`get`、`update` 與 `delete` 管理方法。
- 在 `backend/routers/suggestions.py` 新增對應的 CRUD 端點，供前端進行詞彙管理。
- 將 `location` 地點類別納入 `VALID_CATEGORIES` 支援清單。

### 2. 前端推薦詞管理介面
- 在 `frontend/src/views/SettingsView.vue` 整合全新的「推薦詞管理」區塊，支援分類篩選、關鍵字搜尋、直接編輯與刪除。
- 讓使用者可以直接在設定中維護推薦詞彙庫。

### 3. 地點欄位 autocomplete 下拉選單
- 在 `CreateProjectView.vue` 與 `EditProjectView.vue` 的 `location` 欄位加入自適應下拉選單，自動載入 `location` 類別的推薦詞。
- 當建立或修改專案時，仍可自由填寫全新地點，系統會自動在送出時，透過 `projects.py` 的回收機制將新地點寫入推薦詞庫。

### 4. 測試與回歸修正
- 修復 14 項測試回歸，解決了單元測試中 mock DB session 屬性與模型欄位參數不相容的問題。
- 驗證並確保 `group` / `person` / `budget` / `expense` 等其他推薦詞不受影響。
