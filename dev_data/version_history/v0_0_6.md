# v0.0.6

日期：2026-03-08

## 主題

憑證文字座標校準、前後端單一設定來源、預覽同步與 PDF 輸出收斂。

## 更新重點

1. 新增 `backend/engine/voucher_text_config.py`，將憑證編號、預算科目、金額格、用途、張數、支付日期、支付金額的校準座標集中管理，作為後端唯一真實來源。
2. 新增 `GET /api/voucher/text-config`，讓前端直接讀取同一份欄位設定，結束前後端各寫一套 magic numbers 的狀態。
3. `VoucherGenerator` 改為使用共享設定，支援憑證編號多行輸出、預算科目三字截斷、底部支付金額 `4,607元整`、校準後用途 textbox 與字型路徑 fallback warning。
4. `VoucherEditorView.vue` 新增安全的 `text_preview` 疊加層、頁面 token + pending image loads barrier、深藍字色預覽、載入中 sync guard，以及 `@mousedown.prevent` 刪除選取修復。
5. 憑證編號格式改為逐筆列舉換行，例如 `D-16-01`、`D-16-02`，不再使用 `D-16-01~04` 範圍縮寫。
6. PDF 產生流程改回真正的 blob 下載，前端可從回應標頭解析檔名並直接下載。
7. 補齊後端 router / generator 測試與前端 preview utility 測試，並確認 build、node tests、targeted pytest 全數通過。

## 影響

- 前端預覽與後端 PDF 的欄位邏輯收斂到同一份配置，維護成本顯著下降
- Voucher Editor 回到可實際使用的穩定狀態，且主要回歸點已有測試保護
- 六格金額政策仍維持 deferred 狀態，正式調整移交 V0.0.7
