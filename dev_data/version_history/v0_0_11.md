# v0.0.11

日期：2026-03-15

## 1. 計畫

本版目標聚焦在 Settings 前端恢復與管理能力補齊：

1. 修復設定流程中常見的 runtime 契約問題。
2. 提供 VLM 供應商模型清單自動抓取能力，降低手動填 model name 的錯誤率。
3. 修正群組資料模型，支援同組多位組長。
4. 新增每位組長可上傳多張電子章（供稽核輪替蓋印）。
5. 針對憑證範本座標設定頁的圖片/座標偏移問題進行修復。

---

## 2. 變更紀錄

### 2.1 後端

1. 設定 API：新增 `GET /api/config/vision-models`
   - 依目前 `vision_settings.base_url` + `api_key` 向 OpenAI 相容供應商查詢模型列表。
   - 回傳 provider、count、models。

2. 群組資料：由單一組長欄位提升為可多位組長（相容舊資料）
   - `ProjectRepository` 新增 leader 名單編解碼與移除單一組長能力。
   - `list_groups()` 回傳 `leader_names` 與舊格式 `leader_name`（相容既有前端）。

3. 電子章管理 API（依 group + leader）
   - 上傳多檔：`POST /api/projects/groups/{group}/leaders/{leader}/stamps`
   - 列表：`GET /api/projects/groups/{group}/leaders/{leader}/stamps`
   - 讀檔：`GET /api/projects/groups/{group}/leaders/{leader}/stamps/{filename}`
   - 刪除單檔：`DELETE /api/projects/groups/{group}/leaders/{leader}/stamps/{filename}`
   - 刪除單一組長：`DELETE /api/projects/groups/{group}/leaders/{leader}`

4. 憑證範本預覽 API 強化
   - `GET /api/voucher/config/template-preview` 新增 `pageWidth`、`pageHeight`、`previewPixelWidth`、`previewPixelHeight` 回傳。

### 2.2 前端

1. Settings 頁
   - 新增「自動抓取供應商模型列表」按鈕與快速套用。
   - 群組區塊改為支援多位組長顯示與單一組長刪除。
   - 各組長新增多檔電子章上傳、預覽、刪除功能。

2. 建立/編輯活動頁
   - 群組切換時改讀 `leader_names`，可用 datalist 選擇多位組長之一。

3. 憑證範本座標頁（第一階段）
   - Canvas 改為用後端回傳的實際 PDF 尺寸初始化，避免固定 A4 造成比例失真。
   - 背景圖 fit 邏輯再修正為「以 Fabric 實際載入寬高計算縮放並置中」，避免 DPI/像素比差異導致只顯示 1/4 畫面。
   - 金額格改為顯示完整座標欄位：右側可編輯 `X0 ~ X5` 與 `Y`（不再只有單一 X）。
   - 畫布編輯標記由「點」改為「範例文字」，可直接拖拉文字/文字框檢查實際排版效果。
   - 安全區語義保持 `x0/y0/x1/y1`（左上到右下角座標，對應 `fitz.Rect(x0, y0, x1, y1)`）；
     蓋章死區則使用 `x/y/w/h` 表示。
    - 安全區拖拉手感修正：關閉 centered scaling，並在縮放事件中將 transform 正規化回 width/height，
       讓操作行為更接近直接調整 `x0/y0/x1/y1`。

4. 憑證範本座標頁（第二階段：對位與渲染 bugfix）
   - 設定頁 point 欄位預覽改為共用 `buildVoucherTextPreviewEntries`，避免與實際編輯頁走不同排版邏輯。
   - `voucherNo`/`budgetItem`/`paymentAmount` 不再使用簡化單字預覽，改為套用同等字級、基線、auto-scale 規則。
   - 修正 Fabric API 相容性：由 `object.bringToFront()` 改為 `canvas.bringObjectToFront(obj)`，排除 runtime 錯誤。
   - 修正支付日期預覽不顯示：設定頁 sample 改用 ISO 格式輸入，讓共用 formatter 能正確轉 ROC 日期。

## 3. 問題與處理歷程

### 3.1 主要問題

1. 設定頁欄位預覽與實際編輯頁顯示位置不一致，且偏移方向不統一。
2. 設定頁 runtime 錯誤：`fieldLabelObjs[key].bringToFront is not a function`。
3. 支付日期（payDate）在設定頁預覽無法渲染。

### 3.2 根因

1. 設定頁 point 欄位預覽使用簡化渲染，未與實際編輯頁共用同一套 preview entry 規則。
2. Fabric 7 API 變更，舊物件方法已失效。
3. 設定頁 sample 日期使用 ROC 字串，與共用 formatter 預期的 ISO 輸入不一致。

### 3.3 修復策略

1. 將設定頁 point 欄位改為重用共用 preview builder。
2. 將前景層控制統一改為 canvas 層 API。
3. 將 payDate sample 調整為 ISO 並以測試固定契約。

### 3.4 結果

1. 漂移問題顯著收斂，欄位預覽語義已與編輯頁對齊。
2. runtime 錯誤已消失。
3. payDate 可穩定渲染。

## 4. 圖片與對位狀態

1. 問題描述（原始）
   - 憑證範本座標設定頁曾出現背景只顯示 1/4、預覽比例偏移。

2. 本輪處理結果
   - 已透過 Fabric 實際影像尺寸計算 `fitScale` 並置中，背景顯示大致恢復正常。
   - 使用者回報「大體修好」，可進入持續觀察階段。

3. 觀察與後續
   - 若再次出現偏移，優先檢查：`devicePixelRatio`、瀏覽器縮放比例、Canvas CSS 寬高是否被外層樣式覆蓋。
   - 建議保留最小可重現案例（固定 PDF + 固定座標）作為回歸檢查基準。
