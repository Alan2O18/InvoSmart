# 版本紀錄 - v0.0.15 (印章管理系統)

日期：2026-04-10

---

## 🎯 重點更新 (Key Focus)
本版本實作了「印章管理系統 (Stamp Repository)」，旨在解決手動發票排版時頻繁需要去背或疊加印章的痛點。透過自動偵測圖紙中的多個印章並進行智能去背，將原本繁瑣的影像處理整合為單一工作流。

## ✨ 新增功能 (Added)

### 後端 (Backend)
- **資料庫模型擴展**：於 `models.py` 新增 `Stamp` 模型，支援儲存印章名稱、類別（Category）、群組關聯（Group）與圖片路徑。
- **印章影像處理器 (`StampProcessor`)**：
  - 支援 **「紅色印章模式 (Red Mode)」**：使用 OpenCV 轉換至 HSV 色域，提取兩個紅色區間的遮罩，精準抓取傳統紅章輪廓。
  - 支援 **「黑色/邊緣印章模式 (Edge Mode)」**：使用 Canny 邊緣偵測與形態學膨脹處理，支援黑色或非紅色印章。
  - 自動去背功能：使用 Otsu 閾值二值化抽離背景，預設填充 Alpha Channel 轉為背景透明的 PNG，解決覆蓋發票文字的問題。
- **專屬 API 路由 (`routers/stamps.py`)**：
  - `GET /stamps`：獲取已儲存的全部印章列表。
  - `POST /stamps/detect`：上傳 A4 圖紙，回傳自動偵測出的全部印章邊界框 (Bounding Boxes) 預覽。
  - `POST /stamps/register`：接收選定框的 Metadata，依序裁切、去背、儲存圖片實體並寫入 DB。
  - `DELETE /stamps/{id}`：連動刪除 DB 紀錄與實體 PNG 檔案。

### 前端 (Frontend)
- **管理介面 (`StampsManagementView.vue`)**：全新的管理儀表板，以卡片 (Card) 網格形式展示所有註冊印章，提供刪除與檢視功能。
- **上傳與框選互動對話框 (`StampAssignDialog.vue`)**：
  - 三階段流程：上傳圖紙 -> 智能框選檢視/手動補框 -> 填寫印章屬性。
  - 互動式 Canvas：可透過滑鼠拖拉自訂未被自動偵測抓出的印章區域。
- **狀態管理 (`stamp.js`)**：新增專屬的 Pinia Store 進行 API 封裝及前端狀態管理。

## 🔧 系統優化 (Optimized & Minor Fixes)
- 統一將印章圖片儲存至 `backend/data/stamps/`，並於 `main.py` 註冊新的 StaticFiles 掛載點 `/stamps-static` 進行供圖。
- 支援印章互相重疊時的 Non-Maximum Suppression (重疊抑制)，避免抓到重複影像。
