# v0.0.7

日期：2026-03-09

## 主題

六格金額制度正式上線，並補齊預覽崩潰防護與後端 silent truncation 防線。

## 更新重點

1. `VoucherFieldsStrict.amount` 由 `<= 9999999` 改為 `<= 999999`，正式切換到六格制度。
2. `backend/engine/voucher_text_config.py` 的 amount 欄位改為六格 `xList` 與 `padLength=6`，並新增 `digitPolicy: 6`、`legacyMaxDigits: 7` metadata。
3. `VoucherGenerator._insert_amount_cells()` 新增超長輸入防線，若 amount 超過格數直接丟出 `ValueError`，禁止 silent truncation。
4. 前端 `hasExcessiveAmount` / `formatVoucherAmountCells` 全面改為六格規則。
5. 前端 preview builder 增加 `xList` 邊界保護，避免舊版 7 碼資料造成 Canvas `NaN` 座標崩潰。
6. Voucher Editor UI 的超額提示改為 `999,999` 上限。
7. 測試、API 文件、JSON 結構與測試策略文件同步更新至 V0.0.7 規則。

## 影響

- 這是有意識的 breaking change：strict generate 不再接受七碼金額
- 舊資料不會被靜默截斷，而是明確被攔截並要求修正
- 前端預覽與後端輸出對六格制度的契約已一致
