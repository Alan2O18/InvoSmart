# v0.0.2

日期：2026-03-07

## 主題

修正憑證 PDF 輸出路徑，補上真正下載與 Canvas 文字預覽。

## 更新重點

1. 確認後端 `VoucherGenerator` 原本就會把 `voucherNo`、`budgetItem`、`amount`、`purpose`、`receiptCount`、`payDate` 寫進 PDF。
2. `POST /api/voucher/{project_id}/generate` 改為直接回傳 PDF `FileResponse`。
3. 前端 `generateVoucherFromLayout()` 改為 blob response，編輯器內可直接下載 PDF。
4. 新增 `/api/voucher/fonts/kaiu.ttf`，前端與後端共用 KaiU 字型來源。
5. `VoucherEditorView.vue` 新增文字預覽層、ROC 日期 helper、檔名解析與字型 fallback。
6. `ProjectDetailView.vue` 移除舊版快速產生黏貼紙入口，避免下載錯誤版本 PDF。
7. 新增/更新 voucher router 測試，並完成前端 build 與 utility test 驗證。

## 影響

- 使用者在編輯器中看到的文字位置，能更接近最終 PDF
- 下載路徑與實際產出內容一致，不再誤用舊 API
