# v0.0.5

日期：2026-03-07

## 主題

回補 V0.0.4 破壞後的穩定性，先止血再重新建立正確修正方向。

## 更新重點

1. 明確撤回會破壞 Canvas 狀態主幹的改法，重新把 `canvasLoading`、非同步載入保護與頁面同步機制視為不可隨意觸碰的核心。
2. 將「刪除選取」問題重新定義為焦點處理問題，而非資料刪除問題，確認應採 `@mousedown.prevent` 方案修補。
3. 重新辨識 PDF 欄位的真實輸入格座標，放棄以標題文字位置推算輸入內容的錯誤做法。
4. 確認 `onlyFillEmpty`、字型 fallback 與 textbox 縮字保護等防線必須保留，不能為了修一個 bug 連帶拆掉穩定機制。
5. 為 V0.0.6 建立更嚴格的修補邊界：先校準座標與同步架構，再處理顯示細節。

## 影響

- 專案從「持續修壞」轉回「可以安全落地修補」的狀態
- 後續 V0.0.6 能在明確邊界下收斂，不再重演大範圍回歸
