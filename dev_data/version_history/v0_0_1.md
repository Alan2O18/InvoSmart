# v0.0.1

日期：2026-03-06

## 主題

Voucher Editor 可用性與介面大修。

## 更新重點

1. 左側可用發票清單改為卡片式介面，加入縮圖、日期、金額資訊。
2. 新增較合理的初始放置邏輯，避免發票全部重疊在畫布同一角落。
3. 圖片縮放改為維持比例，不再把長條熱感應發票壓成細線。
4. 底部發票清單從 debug JSON 座標輸出改成可讀管理清單。
5. 修補 Fabric.js 7 相容性、切頁白畫面與同步時序問題。

## 影響

- Voucher Editor 從「只能勉強操作」提升到「可進行實際排版」
- 為後續自動欄位計算、文字預覽與 PDF 正式輸出打下基礎
